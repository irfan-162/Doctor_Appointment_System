# 🩺 Doctor Appointment Management System

A full-stack **Doctor Appointment Management System** built using the **PERN Stack (PostgreSQL, Express.js, React.js, and Node.js)**. The application streamlines the appointment booking process by allowing patients to connect with doctors through an intuitive and responsive web interface while managing healthcare records efficiently.

## ✨ Features

### 👤 Patient

* Register and log in
* View and update personal profile
* Browse doctors by specialization
* Book appointments based on doctor availability
* View upcoming appointments
* Access medical records
* View billing and payment information

### 👨‍⚕️ Doctor

* Manage appointment schedules
* View patient appointments
* Access patient information
* Update treatment details
* Maintain medical records

### ⚙️ System

* RESTful API architecture
* JWT-based authentication and authorization
* PostgreSQL relational database
* CRUD operations
* Appointment scheduling and management
* Input validation and error handling
* Responsive user interface

## 🚀 Getting Started

### Prerequisites

Before running the project, make sure you have installed:

* Node.js
* PostgreSQL
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/irfan-162/Doctor_Appointment_System.git
```

Navigate to the project directory:

```bash
cd Doctor_Appointment_System
```

Install dependencies:

```bash
npm install
```

Configure your PostgreSQL database and create the required environment variables.

Run the backend server:

```bash
npm start
```

Run the frontend:

```bash
npm run dev
```
